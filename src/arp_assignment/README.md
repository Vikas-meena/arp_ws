# ARP Assignment --- Backward Value Iteration Navigation

## 1. Overview

This project implements a grid-based robot navigation system using
**Backward Value Iteration (BVI)** in **ROS 2 Jazzy**.

The system:

1.  Generates a **30 × 30 grid workspace**.
2.  Places approximately **20% obstacles** in the workspace.
3.  Defines:
    -   Start: `(1, 1)`
    -   Goal: `(28, 28)`
4.  Computes the **cost-to-go** from every reachable free cell using
    Backward Value Iteration.
5.  Extracts an optimal policy.
6.  Generates an optimal path from start to goal.
7.  Publishes the map, path, robot pose, cost-to-go visualization, and
    robot/start/goal markers through ROS 2 topics.
8.  Visualizes the complete navigation process in **RViz2**.

### Assignment result from the current implementation

For the current fixed map:

-   Map size: `30 × 30`
-   Total cells: `900`
-   Obstacles: `180`
-   Obstacle ratio: `20%`
-   Start: `(1, 1)`
-   Goal: `(28, 28)`
-   BVI iterations: `57`
-   Optimal path length: `56` moves

## File descriptions

### `map_generator.py`

Creates the grid environment.

Responsibilities:

-   Creates a `30 × 30` grid.
-   Uses `0` for free cells.
-   Uses `1` for obstacles.
-   Generates approximately 20% obstacles.
-   Keeps start and goal cells free.
-   Defines:

``` text
Start = (1, 1)
Goal  = (28, 28)
```

------------------------------------------------------------------------

### `value_iteration.py`

Contains the Backward Value Iteration algorithm.

The robot has four possible actions:

``` text
N = North
S = South
E = East
W = West
```

Each valid movement has cost `1`.

The goal state is initialized with:

``` text
V(goal) = 0
```

The algorithm propagates the cost backward from the goal until the
values converge.

It produces:

``` text
values
policy
```

where:

-   `values[y,x]` = cost-to-go from the state.
-   `policy[y,x]` = optimal action from the state.

------------------------------------------------------------------------

### `path_planner.py`

Uses the policy generated by BVI to construct the optimal path.

It starts from:

``` text
(1,1)
```

and repeatedly follows the optimal policy until:

``` text
(28,28)
```

is reached.

------------------------------------------------------------------------

### `navigation_node.py`

This is the main ROS 2 node.

ROS node name:

``` text
bvi_navigation
```

It:

1.  Creates the grid map.
2.  Runs BVI.
3.  Generates the optimal path.
4.  Publishes ROS 2 messages.
5.  Moves the simulated robot along the optimal path.
6.  Publishes RViz visualization markers.

------------------------------------------------------------------------

# 3. ROS 2 Topics

The navigation node publishes the following topics:

  -----------------------------------------------------------------------------
  Topic                   Message Type                  Purpose
  ----------------------- ----------------------------- -----------------------
  `/map`                  `nav_msgs/OccupancyGrid`      Grid map and obstacles

  `/optimal_path`         `nav_msgs/Path`               BVI optimal path

  `/robot_pose`           `geometry_msgs/PoseStamped`   Current robot position

  `/cost_to_go`           `visualization_msgs/Marker`   Cost-to-go heatmap

  `/robot_marker`         `visualization_msgs/Marker`   Visible moving robot

  `/start_goal_markers`   `visualization_msgs/Marker`   Start and goal markers
  -----------------------------------------------------------------------------

All visualization messages use:

``` text
frame_id = map
```

Therefore RViz should use:

``` text
Fixed Frame = map
```

# 25. Algorithm Summary

The project uses Backward Value Iteration.

For every free state `s`, the value function represents the minimum cost
required to reach the goal.

The goal is initialized as:

``` text
V(goal) = 0
```

For every other state, the algorithm considers the valid neighboring
states and chooses the action with minimum future cost.

With unit movement cost:

``` text
V(s) = min [ 1 + V(s') ]
```

over valid successor states `s'`.

The policy stores the action producing the minimum value.

After convergence:

``` text
Value Function
      ↓
Optimal Policy
      ↓
Path Planner
      ↓
Start → Goal
```
